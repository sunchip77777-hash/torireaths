# 토리레쓰 (ToriReaths)

스레드 제휴 글쓰기 스튜디오 — 한 화면에서 계정별 본문·첫 댓글 초안, 페르소나 말투, 제휴 댓글 템플릿, 역대가 가격비교 카드 PNG를 만드는 단일 HTML 웹앱입니다.

## 쓰는 법
- 접속: https://sunchip77777-hash.github.io/torireaths/
- 아이폰 Safari에서 열고 **공유 → 홈 화면에 추가**를 누르면 앱처럼 전체화면으로 실행됩니다.
- 첫 화면에서 스레드 계정 핸들을 등록하면 바로 쓸 수 있습니다.

## 데이터
- 입력한 계정·페르소나·템플릿·보관함 글은 **브라우저 localStorage에만** 저장됩니다. 서버로 전송되지 않습니다.
- 기기를 바꾸면 'AI 키 · 백업' 화면에서 JSON으로 내보내고 새 기기에서 불러오면 됩니다.

## 파일
- `index.html` — 앱 본체 (외부 프레임워크 없음)
- `manifest.json`, `icon-*.png` — PWA 설치용 매니페스트와 아이콘
- `sw.js` — 오프라인 캐시용 서비스 워커
